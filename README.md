# El Bombero Ltda. · Sitio web

**Presentación de equipos, servicios y capacitación en prevención de incendios.**

Sitio frontend con catálogo, información de cursos y páginas de cotización y clientes. Desarrollado con HTML, CSS, JavaScript y Bootstrap.

## Probar localmente

1. Clona o descarga el repositorio.
2. Abre `index.html` conservando `assets/`, `css/`, `js/` y `data/`.
3. Recorre el catálogo y las páginas de cursos y cotización.

Para revisar la carga de datos y recursos puedes usar un servidor estático local, por ejemplo la extensión Live Server de tu editor.

## Contenido principal

| Ruta | Contenido |
| --- | --- |
| `index.html` | Presentación y navegación principal. |
| `catalogo.html` | Catálogo de equipos. |
| `cursos.html` | Información de capacitación. |
| `cotizacion.html` | Interfaz de cotización. |
| `clientes.html` | Página de clientes. |
| `css/` y `js/` | Estilos e interacciones. |
| `assets/` y `data/` | Recursos y datos del frontend. |
| `Others/` | Archivos adicionales del sitio. |
| `mobile-app/` | Variante de interfaz móvil. |

## Decisión de implementación

Las páginas comparten recursos de estilo y comportamiento para mantener el catálogo y la presentación en una estructura estática. Bootstrap aporta componentes y adaptación a tamaños de pantalla, complementados con estilos propios.

## Alcance

Este repositorio documenta el frontend. No se anuncia una integración de pagos, envío de cotizaciones o gestión de clientes en servidor como si estuviera verificada. Para un uso operativo deben comprobarse las conexiones de formularios, el tratamiento de datos y los servicios de destino.

Los nombres, marcas e imágenes de la empresa conservan sus titulares originales.
